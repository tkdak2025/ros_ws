### 현재 판정 규칙

1. TIMEOUT·Robot/Tool/Safety/Motion 오류·유효하지 않은 데이터 → SYSTEM_ERROR.
2. 유효한 검사에서 Pull 중 최소 실측 폭 **16 mm 미만** → FAIL (`FAIL_GRIP_WIDTH`). 16 mm 자체는 미만이 아니다.
3. FORCE_LIMIT + 허용 변위 이내 → PASS, 초과 → FAIL.
4. MAX_DISTANCE → FAIL.
5. Soft 기준 폭은 추가진입을 마치고 Soft 동작이 끝난 뒤, Hard 명령 직전에 측정한다.
6. `width_delta_mm = Pull 최소 폭 - Soft 기준 폭`은 기록용이며 허용 차이로 판정하지 않는다.
7. MISSING과 별도 Slip 판정은 사용하지 않는다.
8. 제품 결과 SYSTEM_ERROR가 기록되었다는 것과 Robot이 안전하게 Home 이동 가능한 것은 별개다. 실제 모션 오류는 정상 복귀를 강행하지 않는다.

### 현재 실행 흐름

```text
START → #01 Initialize → #02 Home Return → Work Access
 → 활성 Point 순회 (#03 → #04 → #05, #06은 비동기)
 → Work Access → #07 완료 확인 → #02 Home Return → SYSTEM_READY
```
