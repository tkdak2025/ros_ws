# 검사파트 기능 검증 체크리스트 v4

기준: 2026-09-25, HMI 전담 노드 분리 및 START/완료 Work Access 정책 반영 후.

현재 작업 흐름은 **START → 장비·레시피 점검 → 현재 위치별 Work Access 확보 → 포인트 순회 → Work Access 복귀 → 판정·기록 완료 → SYSTEM_READY 대기**다. 검사 시작·완료 시 자동 Home은 없으며 Home은 별도 명령으로 실행한다.

## 1. 확인 방법과 기록

- **V — 가상모드 운전:** 가상 로봇·그리퍼와 terminal/HMI 입력으로 위치·순서·상태 전이를 확인한다.
- **D — 데이터/통신 모의:** 위치·힘·폭·서비스 응답·시간을 재현하여 종료 조건과 오류 분기를 확인한다. 가상 로봇만 구동해서 실제 접촉 저항이 재현된 것으로 보지 않는다.
- **R — 실물 확인:** 실제 접근 방향, 간섭, 그리퍼 개방·파지, 힘·변위의 적절성을 확인한다.
- **C — 코드/ROS 구성 확인:** 노드 소유권, 연결 재사용, 통신 계약과 기록 구조를 확인한다.

체크박스는 해당 시험을 직접 수행하고 기대 결과와 증거를 확인한 후 표시한다. 기존 자동 테스트 통과만으로 실물 확인까지 완료 표시하지 않는다. 아래의 C/D 시험은 필요 시 별도 테스트 클라이언트를 사용하며 HMI 화면 코드를 수정할 필요는 없다.

| 기록 항목 | 입력 |
|---|---|
| 실행 날짜 / 확인자 | |
| 코드 버전 또는 빌드 시각 | |
| robot_mode / control_mode / ROS_DOMAIN_ID | |
| Recipe ID / version / 사용 포인트 | |
| request_id / run_id / 결과 폴더 | |
| 실패 항목 ID / 실제 현상 / 로그 경로 | |

가상모드 실행은 [v4 실행·검증 안내](02_실행과_정량검증_가이드_v4.md)의 환경 설정을 사용한다. 콘솔은 `1 START / 2 PAUSE / 3 RESUME / 4 STOP / 5 HOME / 6 레시피 선택 / 7 상태 조회`다.

- [ ] R02 — Open 25 mm가 실제 파지를 해제하며 인접 케이블과 간섭하지 않는가.
- [ ] R03 — Tool 반대 방향 30 mm 후퇴와 이후 Work Access 이동이 실제 접촉을 해제하고 간섭을 피하는가.
- [ ] R04 — Soft/Hard 폭·힘 및 안정화 조건이 정상 파지를 놓치거나 잘못된 파지를 정상으로 보지 않는가.
- [ ] R05 — 정상체결·체결불량 실물 데이터에서 힘·변위·폭 판정 기준이 적절한가. LAN 기준 힘은 현재 15 N이다.

## 11. 우선 실행 순서

1. A01~A02: 기동·노드·통신 경로 확인.
2. C01~C04, G01, G03: Home/Access/작업영역의 START, STOP 후 재시작, Access 완료·연속 실행.
3. D01~D03, D10: 접근·진입·Pull·복귀의 모션 순서.
4. F01~F05: Pause/Resume/STOP과 통신 복구.
5. D04~D09, E01~E05, C07, G02: 실물 데이터를 가정한 피드백·오류 분기.
6. B01~B07, H01~H04: HMI 계약·Recipe·표시·파일 대조.
7. G04~G06과 R01~R05: 수동 Home과 실물 적합성 확인.
