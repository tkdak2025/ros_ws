# 실물 로봇 현장 검증 체크리스트

작성일: 2026-09-29 · 대상: M0609 / OnRobot RG2 / cable_inspection

사용자가 직접 운전하고 기록하는 현장 시험표다. 모든 항목은 미실행 상태로 시작한다. 자동시험 통과 이력은 실물 시험 결과로 대신하지 않는다.

기준 문서: [기능 검증 체크리스트](01_기능검증_체크리스트_v4.md), [실행 가이드](02_실행과_정량검증_가이드_v4.md), [시스템 설정](../../../../src/cable_inspection/config/system_recipe.json).

## 2. 운전 전 준비

- [ ] P01 — 비상정지 위치와 조작 담당자를 확인하고 로봇 이동 범위 내 사람·장애물을 정리했다.
- [ ] P02 — 공구·그리퍼·시험품·케이블 고정 상태와 배선 여유를 확인했다.
- [ ] P03 — 로봇/RG2 전원·LAN·드라이버 연결을 확인했다. 드라이버를 중복 실행하지 않는다.
- [ ] P04 — 드라이버와 검사 프로그램 모두 real 모드이며, HMI 사용 시 두 PC의 ROS_DOMAIN_ID와 cable_interfaces 버전이 일치한다.
- [ ] P05 — 코드 변경 후 빌드·환경 source·검사 프로그램 재시작을 완료했다.
- [ ] P06 — 실제 Tool/TCP와 레시피의 joint/task 교시값이 같은 공구·자세 기준인지 확인했다.
- [ ] P07 — Home·Work Access·각 Ready/Entry 자세와 이동 경로를 현장 배치에 대조했다. 저장된 예시 좌표를 그대로 적합하다고 간주하지 않는다.
- [ ] P08 — 첫 시험은 검증할 포인트 하나만 활성화하고 실제 적용 속도·힘·거리·시간을 기록했다.
- [ ] P09 — 결과 저장 경로와 쓰기 권한을 확인했다.

### 적용값 기록

아래 값은 저장소의 작성 시점 기준이다. 실제 실행에 사용한 설정·Snapshot을 대조한다.

| 설정 | 저장소 기준 | 실제 적용값 / 확인 |
|---|---|---|
| 공통 관절 속도 | 10 °/s | |
| Open 폭 / 힘 | 25 mm / 10 N | |
| 작업영역 내부 후퇴 | 현재 Tool −Z, 30 mm | |
| Home joint | 모든 관절 0° | |
| Home 관절 허용오차 | 0.1° | |
| Heartbeat 만료 / 통신 복구 제한 | 2 s / 30 s | |
| 판정 대기 제한 | 10 s | |
| Soft / Hard 폭·힘 및 안정화 조건 | 현재 레시피·코드 확인 | |
| Entry / Pull 거리·속도·시간·힘 제한 | 현재 레시피 확인 | |
| 판정 힘 / 변위 / 최소 폭 기준 | LAN 문서 기준 힘 15 N, 최소 폭 16 mm; 실제 조건 대조 | |

힘 제한값은 정지 요청 기준이며 실측 최대 힘의 상한을 보장하지 않는다. 정지 후 감속 구간의 최대 힘도 기록한다.

## 4. 단일 포인트 — 방향·파지·접촉 우선 검증

경로·방향·해제가 예상과 다르면 해당 시험을 중단하고 원인을 기록한다. PAUSE는 즉시 정지가 아니라 원자 동작 완료점에서의 정지 요청이다.

| 완료 | ID | 조작·확인 | 기대 결과 | 관측 / 증거 |
|---|---|---|---|---|
| [ ] | M01 | Home 등 작업영역 밖에서 START | 장비 점검 → Work Access 도달 → 첫 포인트 접근. 불필요한 Home 경유 없음 | |
| [ ] | M02 | Ready / Entry 접근 관찰 | Open → Ready MoveJ → Entry MoveJ, 실제 도달 후 접촉 검사 | |
| [ ] | M03 | Entry 자세의 축과 실제 이동 방향 확인 (R01) | 추가 진입 Tool +Z가 케이블 진입 방향, Pull은 반대 방향 | |
| [ ] | M04 | Soft Grip 및 추가 진입 관찰 (R04) | Soft 명령 → 진입 → 새 실측 폭 기록. busy만으로 진행을 막지 않음 | |
| [ ] | M05 | Hard Grip 완료와 Pull 시작 확인 (R04) | 목표 폭 도달 또는 폭 안정화 후 Pull. 케이블 미끄러짐·손상 여부 기록 | |
| [ ] | M06 | 진입/Pull 종료 확인 | 실제 거리·힘·시간·종료 사유 기록. 접촉 저항으로 미도달한 값을 목표 거리로 바꾸지 않음 | |
| [ ] | M07 | 정지 전후 샘플 대조 | 감속 구간까지 최대 Pull 힘·최소 폭 집계에 포함 | |
| [ ] | M08 | Pull 후 Open 확인 (R02) | 25 mm 개방으로 실제 파지 해제, 인접 케이블 간섭 없음 | |

## 6. PAUSE·STOP·통신 복구

정상 단일 포인트 검증 후 간섭 없는 조건에서 진행한다. 통신 시험은 HMI/콘솔 Heartbeat 경로를 대상으로 하며, 운전 중 로봇 전원이나 장비 LAN을 뽑아 대신하지 않는다.

| 완료 | ID | 조작·확인 | 기대 결과 | 관측 / 증거 |
|---|---|---|---|---|
| [ ] | C01 | 검사 중 PAUSE → 정지 상태 확인 → RESUME | 원자 동작 완료점에서 대기, 문맥 보존, 장비 재확인 후 이어서 진행 | |
| [ ] | C02 | 이동 중 STOP | 정지 처리 후 Job 종료, 자동 Home·다음 포인트 이동 없음 | |
| [ ] | C03 | PAUSED에서 STOP | 대기 Job 종료, 이전 문맥 폐기 | |
| [ ] | C04 | STOP 완료 및 원인 확인 후 새 START | HOME 필수 없이 현재 위치에 맞게 Access 확보, 새 Job 시작 | |
| [ ] | C05 | Heartbeat 중단 후 복구 제한 내 복원 | Safe Pause 요청, 복구만으로 자동 재개하지 않고 RESUME 대기 | |
| [ ] | C06 | Heartbeat 복구 제한 초과 | COMM_ERROR로 중단, 자동 Home 없음 | |
| [ ] | C07 | 실행/일시정지/정지 처리 중 START·HOME 추가 입력 | 중복 Worker·동시 모션 없이 거절 사유 표시 | |

## 7. HMI 연동 — terminal 단독 시험이면 해당 없음 기록

- [ ] H01 — START accepted는 접수로 표시하며 완료로 표시하지 않는다. run_id와 Snapshot이 실행과 일치한다.
- [ ] H02 — 같은 request_id·같은 레시피 재전송은 ALREADY_ACCEPTED이며 재실행하지 않는다.
- [ ] H03 — 같은 request_id·다른 레시피는 REQUEST_ID_CONFLICT이며 현재 실행을 변경하지 않는다.
- [ ] H04 — 활성 포인트·진행률·PAUSED/STOPPED/ERROR/SYSTEM_READY·판정이 실제 상태와 일치한다.
- [ ] H05 — 연결 유실이나 만료된 값이 정상 최신값으로 표시되지 않는다.

## 8. 정상체결·체결불량 비교 (R05)

사전에 체결 상태를 확인한 시험품으로 같은 레시피에서 반복한다. 반복 횟수는 시험 전에 정하고, 시험품을 재사용하면 이전 Pull로 상태가 바뀌었는지 확인한다. SYSTEM_ERROR는 제품 불량과 구분한다.

|---|---|---|---|---|---|---|---|---|
| 정상체결 | 1 | | | | | | | |
| 정상체결 | 2 | | | | | | | |
| 정상체결 | 3 | | | | | | | |
| 체결불량 | 1 | | | | | | | |
| 체결불량 | 2 | | | | | | | |
| 체결불량 | 3 | | | | | | | |

- [ ] Q01 — 정상/불량의 힘·변위·폭과 실제 판정 사유를 대조했다.
- [ ] Q02 — 오검출·미검출·SYSTEM_ERROR를 별도로 집계했다.
- [ ] Q03 — 기준값 적합성을 검토하고 변경 필요 시 근거와 재시험 대상을 기록했다. 단일 성공으로 전체 제품 검증을 완료하지 않는다.

## 10. 실물에 의도적으로 만들지 않을 오류 분기

아래 항목은 모의시험 증거를 검토하거나 별도 통제된 시험으로 수행한다. 충돌·과부하·강제 구속으로 오류를 만들지 않는다. 현장에서 자연 발생하면 로그를 보존하고 기대 동작과 대조한다.

| 검토 | 항목 | 기대 동작 / 증거 경로 |
|---|---|---|
| [ ] | Ready/Entry 접근 미도달 (U02) | 후속 파지·접촉 이동 차단, 정지·오류 기록 / |
| [ ] | Open 실패·후퇴 미도달·Access 미도달 | 후속 검사 차단 / |
| [ ] | Hard Grip 완료 타임아웃 | SYSTEM_ERROR, Pull 생략, Open → Entry → Ready 복구 성공 시 다음 포인트 / |
| [ ] | 파지 실패 복구 중 오류·STOP | Job 중단, 다음 포인트 미실행 / |
| [ ] | Tool/TCP·모드 불일치·비정상 피드백 | 준비/도달 확인 실패, 검사 차단 / |
| [ ] | 늦은 판정·결과 누락·저장 실패 | 실행 간 결과 혼입 방지, 완료 조건 미충족 시 정상 완료 금지 / |
