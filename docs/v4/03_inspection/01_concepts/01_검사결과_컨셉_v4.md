## 목적과 구분

검사결과는 케이블의 기계적 체결상태를 판단하기 위한 결과다. 전기적 연결 품질이나 시스템 전체의 정상 여부를 대신하지 않는다.

| 구분 | 현재 값 | 의미 |
|---|---|---|
| 제품/시스템 결과 | PASS / FAIL / SYSTEM_ERROR | 계측 조건에 대한 판정 또는 검사 성립 실패 |
| 판정 진행 | PENDING / COMPLETED / ERROR | 비동기 요청의 처리 상태 |
| 모션·시퀀스 | SUCCESS / FAIL / INCOMPLETE 등 | 절차 및 복구 수행 상태; 결과와 별도 |
| Job | 완료/정지/오류·대기 상태 | 포인트 순회, Access 복귀, 판정·기록 집계 상태 |

PASS는 유효한 힘 제한 종료, 폭 조건, 허용 변위 조건을 만족한 경우다. FAIL은 유효한 검사에서 폭·최대거리·변위 기준을 벗어난 경우다. SYSTEM_ERROR는 타임아웃, 힘 기준 전 이동 중단, 잘못된 계측 등의 이유로 정상 판정을 확정할 수 없는 경우다.

파지 실패나 좁은 폭만으로 케이블 누락(MISSING), 완전 이탈(DETACHED)을 확정하지 않는다. 이전 컨셉에 있던 세부 분류는 현재 결과 인터페이스의 보장값이 아니다.

## 완료와 합격의 분리

복구에 성공한 Hard 파지 timeout 포인트는 SYSTEM_ERROR로 기록하고 다음 포인트를 수행할 수 있다. 모든 포인트의 모션·결과·저장이 정리되면 Job은 완료될 수 있다. 따라서 `completed=true`를 제품 전체 PASS로 표시하면 안 된다. 결과별 개수와 point_id별 판정 사유를 확인한다.

## 추적 단위

request_id는 HMI 접수 요청, run_id는 실행, recipe_id/version은 고정 조건, point_id는 실행 내 위치를 식별한다. 제품 DB의 cable_id/product_id와 같다고 가정하지 않는다. 현재 전송 메시지에 없는 제품 식별자는 HMI에서 별도로 관리한다.

결과에는 종료 사유, 최대 힘, 실제 변위, Soft 폭, Pull 최소 폭, 폭 차이, 사용 기준을 보존한다. 판정 순서·경계값은 [#06 상세 설계](../02_sequences/06_Inspection_Judgment_Sequence_v4.md)를 따른다.
