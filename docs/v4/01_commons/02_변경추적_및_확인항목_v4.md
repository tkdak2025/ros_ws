## 3. 구현 반영 상태와 남은 확인 항목

| ID | 현재 확인 사실 | 후속 결정/검증 | 관련 문서 |
|---|---|---|---|
| U01 | 구현 완료: 현재 Access 확인 후 직접 Home | 사용자 승인 반영. real/virtual 및 HOME_RETURN/MOVE_HOME 위치별 회귀시험 통과 | #02, G04~G06 |
| U02 | 구현 완료: 접근 도달 실패 시 후속 파지 차단 | 사용자 승인 반영. Ready/Entry·real/virtual 미도달 및 Main 오류 기록 시험 통과 | #03, D01 |
| U03 | 초기 요구 중 현재 미구현/범위 미확정 기능 존재 | 아래 범위 이관 표를 검토하여 별도 구현/보류/제외 결정 | BRD |
| R01~R05 | 실제 방향·해제·간섭·파지·판정 적합성 미확정 | 실물 증거와 Recipe 버전을 함께 기록 | 체크리스트 |

사용자의 “그렇게 수정해” 승인으로 U01/U02를 운영 코드에 반영했다. 수동 Home은 현재 Access 여부를 스스로 확인하며, 접근의 미도달 허용을 제거했다. 접촉 Entry/Pull 처리와 HMI 계약은 유지했다. U03 범위 판단과 R01~R05 실물 적합성 확인은 남아 있다.

## 4. 초기 범위의 이관 — 삭제 승인으로 간주하지 않음

| 초기 요구/구상 | 현 구현 | 관리 방식 |
|---|---|---|
| Micro-Wiggle/Fine Alignment | Soft Grip+축방향 진입; 별도 흔들림/정렬 없음 | 추가 필요성 재검토 |
| 독립 connector axis/entry_direction | Entry 자세의 Tool +Z로 계산 | 현재 방향 기준은 합의 완료. 별도 입력 추가는 필수 잔여 작업이 아님 |
| 힘 유지 검사 | 힘 도달 시 정지·변위 판정 | hold 기능 도입 시 별도 설계 |
| MISSING/DETACHED·slip 상세 분류 | PASS/FAIL/SYSTEM_ERROR, 폭 차이 기록 | 실물 분포·분류 기준 확보 후 검토 |
| contact_area/작업영역 완전 이탈 | 고정거리 Escape 후 Access | 정책은 현행 기준으로 정리. 물리적 적합성 R03은 남음 |
| 자동 경로 생성·충돌 보장 | 교시 자세/설정 경로, 영역 분기 | 현재 보장 기능으로 표시하지 않음 |
| CSV 자동 저장·HMI DB ACK | JSON/JSONL 로컬 기록, db_saved=false | HMI 협의 후 별도 계약 |

## 5. 문서 상태와 증거

작업내역과 v1~v3는 변경 경위를 보존하는 자료다. 현재 기준을 찾을 때는 [v4 색인](../00_문서안내_v4.md)을 사용한다. 오래된 문서 안의 삭제 파일명, 테스트 건수, 당시 자동 Home 결과는 현재 동작 설명으로 인용하지 않는다.
