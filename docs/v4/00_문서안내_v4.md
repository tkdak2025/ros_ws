## 버전·이력 관리

[작업내역 목록](../작업내역/00_작업내역_목록.md)에 번호 문서의 원래 위치와 SHA256을 남겼다. 기존 v1~v3와 과거 결과 파일은 보존한다. v4 Markdown이 최신 기준이며 구버전 PDF/DOCX/ZIP는 자동 갱신되지 않는다.

동일 주제의 옛 문서가 남아 있어도 현재 운영 기준은 이 묶음이다. 미확정 정책을 현 코드와 같다는 이유로 승인된 설계로 바꾸지 않는다. 앞으로 결정이 바뀌면 BRD/컨셉/관련 시퀀스/검증 항목을 함께 갱신하고 근거를 작업내역에 남긴다.

Git 공유 기준 문서 위치는 워크스페이스 내부 `docs/v4`다. v1~v3의 Markdown/YAML 근거 문서도 함께 보존하며, 상위 프로젝트의 기존 PDF/DOCX/영상은 로컬 원본 위치에 유지한다.
