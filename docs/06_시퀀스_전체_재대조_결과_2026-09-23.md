# 06. 시퀀스 전체 재대조 결과

기준: 2026-09-22 설계 묶음 + 이후 사용자 확정 조건. 범위: 검사 측 #00~#07, Common #01. HMI 코드·msg/srv 필드 구조 변경 없음.

## 이번 수정

1. Safe Escape: 영역 경계까지 거리 계산과 이동 후 영역 탈출 검사를 제거. 현재 TCP 자세를 기준으로 Tool −Z 방향 30 mm 직선 후퇴, TARGET_REACHED 확인 뒤 Access/Home 진행. 자세각 유지. 별도 contact_area 없음.
2. Pause: 설계에 있는 PAUSED 중 Robot/System 오류 처리가 RESUME 때까지 지연되는 차이를 발견. PAUSED 진입 및 약 1초 간격 장비 재확인 추가. 실패 시 호출자에서 ERROR/모션 정지 처리. 자동 RESUME 없음.
3. 문서: Home의 경계 탈출 해석 및 불필요한 escape_clearance_mm 제거. max_escape_distance_mm 이름은 호환성을 위해 유지하며 현재는 후퇴거리 30 mm를 뜻한다.

work_area는 기존 Home 내부/외부 분기에만 사용한다. 내부: Open→후퇴→Access→Home, 외부: 직접 Home. 현재 사용자 지정 Home은 전체 관절 0도다. 그리퍼 Open 목표 25 mm, 기존 폭 허용오차 2.5 mm와 idle 확인을 사용한다. MoveL 목표 검증은 기존 위치 0.5 mm/자세 1도 허용오차를 사용한다.

## 다른 시퀀스에 대한 답변

소스와 오프라인 테스트로 재대조한 **주요 실행 순서·완료 게이트에서 추가로 확인된 미해결 불일치는 없다**. 아래 후속 합의는 원래 9/22 문구와 다르지만 코드 누락이 아니라 현재 적용 기준이며 활성 Markdown에 반영했다. 실제 장비의 모든 예외 동작을 검증했다는 뜻은 아니다.

| 대상 | 확인 결과 | 원래 설계와 다른 후속 합의/보완 |

| #00 Main | Initialize→Home→Access→활성 Point 순회→Access→Finish→Home; STOP 자동 Home 없음 | 시작은 전체 레시피 서비스/request_id/snapshot. 기존 토픽 START로 되돌리지 않음 |

| #02 Home | Open→Tool 역방향 후퇴→Access→Home 또는 외부 직접 Home. 실패 시 다음 단계 차단 | 이번 Safe Escape 구체화 반영, 25 mm Open·30 mm 후퇴·0도 Home |

| #04 Grip | Soft→추가 진입→Soft 완료 폭 기록→Hard 완료→Pull | 옛 Hard 직후 폭 대신 Soft 기준 폭; 방향은 Entry ABC의 Tool +Z |
| #05 Pull | 힘/거리/시간 종료, 정지 중 샘플 포함, 비동기 판정→Open→Entry→Ready | LAN 15 N 유지(원문 20 N과 차이), 속도/조건은 확정 레시피 사용. 거리 25 mm·timeout 10초 상한 |

## 검증과 한계

- 최종 오프라인 회귀 결과: **160 passed**. `git diff --check` 통과.
- 새 Safe Escape 테스트: TCP 자세별 반대 방향, 30 mm 목표, 비정상 거리, 미도달 응답, 모션 예외.
- 전체 Home 실패 단계 테스트에서 후속 Access/Home 차단 확인.
- PAUSED에서 로봇 오류가 발생하면 RESUME 없이 ERROR로 종료되고 다음 검사 Point가 실행되지 않는 Job 테스트.
- 기존 초기화·판정·통신복구·STOP·완료 보류·원시 기록·최종 기록 테스트 포함.
- 실물 명령 및 ROS launch 시험은 실행하지 않음. 30 mm 후퇴거리, 파지 해제, 후퇴 이후 Access 경로는 사용자가 실물 확인할 항목이다.
- 활성 설계 Markdown은 갱신했으나 이전 PDF와 docs/v3 보존 사본은 재생성하지 않았다.
