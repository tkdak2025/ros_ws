# M0609 케이블 체결상태 검사 프로젝트

## BRD 논의 합의사항 정리

문서 버전: v0.1  
문서 성격: 상세 시나리오 작성 전의 범위·조건·검사항목·결과 처리 합의사항

## 1. 프로젝트 목적과 범위

M0609이 제품별 Recipe에 따라 서로 다른 위치·방향의 케이블 체결상태를 접촉식 Pull Test로 검사하는 시스템이다. 핵심은 다품종 검사에 대한 대응이며, 이탈 케이블 회수는 예외처리에 포함한다.

| 항목 | 현재 합의사항 |
|---|---|
| 로봇·툴 | Doosan M0609 / OnRobot RG2 |
| 제품 Recipe | 2개 |
| 기본 검사 위치 | 제품 하부 및 측면 |
| 사용 케이블 | RJ45 랜선, HDMI, USB |
| 추가 구현 후보 | 시간이 남으면 상부 검사 추가 |
| 보류 케이블 | RGB/VGA, DVI - 나사 체결 구조 때문에 보류 |
| 비전 | 현재 범위에서 사용하지 않음 |
| 자동 재체결·수리 | 현재 범위 밖 |

검사 대상은 **기계적 체결 유지 상태**이며, 전기적 도통이나 통신 품질을 직접 검사하는 것은 아니다.

## 2. Recipe와 검사지시서의 역할

제품 Recipe는 검사할 Point와 순서를 지정하고, 검사지시서는 각 Point를 어떻게 검사할지 고정한다.

| 구분 | 관리 내용 |
|---|---|
| 제품 Recipe | 제품 식별, 검사 Point 목록·순서, Point별 적용 검사지시서 |
| 검사지시서 | 케이블 종류, 기준 체결 위치·방향·각도, 지정 툴·TCP, Waypoint, 탐색·파지 조건, Pull 조건·판정 기준, 후퇴·회수 조건 |
| 검사 결과 | Point별 측정값, 판정, 미수행 사유, 회수 결과, 적용 지시서 버전 |

툴·케이블 배치·작업공간이 바뀌면 관련 조건을 재검증하고 검사지시서를 개정한다.

## 3. 접근·파지에 대한 전제조건

지정된 툴이 접근하고 파지할 수 있도록 검사 환경을 사전에 구성한다.

| 구분 | 정리된 내용 |
|---|---|
| 접근 가능성 | 접근·탐색·Pull·후퇴 공간을 사전에 확보 |
| 파지 가능성 | 잡을 부위와 툴의 파지 조건을 사전에 검증 |
| 접촉 탐색 | 지정된 기준 위치 주변의 제한된 범위에서 파지 위치를 보정 |
| 실제 파지 성공 | 매 검사에서 확인해야 하는 항목 |
| 범위 밖 | 임의의 배치에서 접근·파지 가능성을 자동 판단하는 기능 |

**“잡을 수 있는 환경인가?”는 사전에 해결하고, “이번에 제대로 잡았는가?”는 실행 중 확인한다.**

## 4. 검사항목과 파지 유효성

| 구분 | 확인할 내용 |
|---|---|
| 체결 유지 | 설정한 Pull 힘·유지시간 조건에서 체결이 유지되는가 |
| 허용 변위 | Pull 방향 변위가 허용 범위를 초과하는가 |
| 완전 이탈 | 검사 중 케이블이 연결부에서 완전히 빠지는가 |
| 파지 유효성 | 대상을 정상적으로 잡았고, 검사 중에도 파지가 유지되는가 |

파지 확인 방법으로 그리퍼 피드백·개구 폭, 제한된 예비 인장, 검사 중 힘·변위 변화를 검토했다. 구체적인 조합과 기준은 아직 확정하지 않았다.

TCP 변위에는 케이블 변형·미끄러짐·Fixture 변형이 포함될 수 있다. 힘의 급감만으로 이탈과 미끄러짐을 구분할 수는 없다는 점을 반영해야 한다.

## 5. 검사 결과와 예외처리

| 결과 | 의미 | 처리 |
|---|---|---|
| PASS | 유효한 검사에서 체결 유지 조건 충족 | 결과 기록 |
| FAIL_DISPLACEMENT | 유효한 검사에서 허용 변위 초과 | 불량 결과 기록 |
| FAIL_DETACHED | 케이블 완전 이탈 확인 | 예외처리로 안전 회수, 결과 기록 |
| MISSING | 검사를 시도했으나 파지 문제 등으로 유효한 검사를 완료하지 못함 | 사유 기록, 안전 후퇴 후 다음 Point 진행 |

파지 관련 검사 미수행은 기존 TEST_ERROR 대신 **MISSING**으로 정리했다. 그 밖의 장비·제어 오류까지 모두 MISSING으로 통합할지는 아직 정하지 않았다.

- MISSING은 제품 불량이나 케이블 부재를 의미하지 않는다.
- MISSING 상태와 사유는 **HMI 및 검사시트·결과보고서에 표시**한다.
- MISSING이 남은 제품은 전체 PASS로 처리하지 않고 미검사 Point가 있음을 표시한다.
- 이탈 케이블 회수는 **재조립이 아닌 안전한 후처리**이다.

## 6. 아직 정해야 할 사항

- Recipe별 케이블 배치와 검사 Point 수
- USB 등 실제 사용할 커넥터의 세부 규격
- 파지 성공 확인에 사용할 피드백과 판정 기준
- 시험 힘·유지시간·허용 변위 등 정량 조건
- 이탈과 파지 미끄러짐을 구분하는 방법
- 케이블 연결 상태를 고려한 회수 위치·경로
- 재파지 시도 여부·횟수와 제품 전체 결과의 집계 기준
