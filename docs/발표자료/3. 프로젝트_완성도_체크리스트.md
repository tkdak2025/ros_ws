# 프로젝트 완성도 체크리스트

| 평가 항목 | 평가 질문 | 우리 프로젝트의 근거 | 보완할 점 |
| -------------- | -------------------------------- | ------------------------------------------- | -------------------------- |
| **목표 달성도** | 체결 검사를 자동으로 수행하고 결과를 판단하는가? | 실물 접근·파지·Pull·복귀·판정·HMI 결과 표시 구현 | 다양한 체결 상태에서 검사 성능 검증 |
| **통합 완성도** | 개별 기능이 하나의 작업 흐름으로 연결되는가? | HMI → 레시피 전달 → 다중 포인트 검사 → 결과 저장·조회 | 최신 조합 레시피의 반복 운전 확인 |
| **현장 운영성** | 작업자가 검사·중단·재개·복귀를 수행할 수 있는가? | 운영 HMI, PAUSE·RESUME·STOP·HOME, 통신 상태 표시 | 오류별 조치 안내와 작업자 사용성 평가 |
| **유연성·확장성** | 검사 대상이 바뀌어도 쉽게 대응할 수 있는가? | 레시피로 좌표·순서·파지·판정 조건 변경 | 레시피 변경 승인·버전 관리 체계 |
| **기술적 차별성** | 단순 반복 이동 이상의 검사 전략이 있는가? | 단계별 Adaptive Grip, 힘·변위 판정, 영역별 Safe Escape | 파지 안정성과 복귀 적용 범위 검증 |
| **검증 체계성** | 구현 결과를 객관적인 기준으로 확인했는가? | **자체 기능검증 체크리스트**, 기대 결과·예외 상황 구분, 회귀시험 | 요구사항별 시험 증거·완료 상태 연결 강화 |
| **문제 해결 역량** | 실패 원인을 분석하고 설계를 개선했는가? | FK로 관절각 오기 확인, 초기 닫힘 원인 분석, 이탈 방식 개선 | 완화 조치와 근본 해결을 구분해 추적 |
| **신뢰성·복구성** | 실패 시 잘못된 다음 동작을 막는가? | 도달·개방 실패 차단, 단일 모션 실행권, 영역 밖 HOME 차단 | 통신 유실·장시간 운전·다양한 중단 위치 검증 |
| **데이터 추적성** | 검사 결과와 당시 조건을 다시 확인할 수 있는가? | 실행 Snapshot, 측정 로그, 결과 이력, Excel 출력 | 데이터 보존·백업·버전 연결 정책 |
| **측정·판정의 타당성** | PASS/FAIL 기준이 실제 체결 상태를 잘 구분하는가? | 힘·변위·폭·종료 사유를 구분해 판정 | 반복성, 정상·불량 샘플, 오검출·미검출률 측정 |
| **유지보수성** | 수정 위치와 영향 범위를 파악하기 쉬운가? | ROS 2 기반 역할 분리, 장비 API·시퀀스·판정 분리, 문서화 | 공통 설정 중복과 오래된 참조 정리 |
| **한계 인식의 명확성** | 검증하지 못한 내용을 성과로 과장하지 않는가? | 순응제어 미구현, 실물 경로 검증·파지 튜닝 과제 명시 | 후속 과제의 우선순위와 완료 기준 설정 |
