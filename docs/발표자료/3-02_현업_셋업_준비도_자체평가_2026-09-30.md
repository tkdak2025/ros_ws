# CCCIS 현업 셋업 준비도 자체 평가

평가 기준일: 2026-09-30

## 평가 기준

현업에 설치하여 작업자가 반복 운영하는 조건에서 기능·신뢰성·검사 성능·안전 검증·유지관리를 평가한다. 확보한 근거에 따른 잠정 자체 평가이며 고객사 검수, 인증, 산업 공통 평가 점수가 아니다. 미검증 항목은 낮게 반영했다.

시제품 기능 완성도와 평가 목적·가중치가 다르므로 두 점수를 같은 척도로 비교하지 않는다. 가중 종합점수 = Σ(항목 점수 × 가중치) / 100.

## 해석과 발표 문구

현재 가장 큰 차이는 기능 부족보다 검증 근거 부족이다. HMI와 레시피 구조는 현장 운영을 고려했지만, 작업물과 상황이 달라져도 반복해서 정확히 동작한다는 증거가 더 필요하다.

> 시제품 기능 완성도는 약 80점, 현장 셋업 준비도는 약 55점으로 자체 평가했습니다. 운영 인터페이스와 검사 자동화는 구현했으며, 양산 적용을 위해 검사 정확도·반복 운전·안전성 검증을 우선 과제로 선정했습니다.

안전성과 필수 검사 성능은 총점으로 상쇄할 수 없는 별도 통과 조건이다. 해당 항목들이 확인되지 않으면 총점이 높아져도 상시 운영 가능으로 판단하지 않는다.

계산 정정: 대화에서 제시한 55.0점은 합산 오류다. 항목 점수·가중치를 유지하고 재계산한 값은 55.3점이다.
