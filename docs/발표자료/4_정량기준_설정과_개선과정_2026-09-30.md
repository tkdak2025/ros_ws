# CCCIS 정량 기준 설정과 개선 과정

정리 기준일: 2026-09-30

## 과정과 구분

초기 기준 설정 → 실물 측정 → 실패 원인 분석 → 기준 수정 → 재검증의 흐름으로 정리한다. 제품 합격 기준, 장비 동작 설정, 오류 완화값은 구분한다. 모든 설정값을 통계적으로 도출하거나 양산 기준으로 검증한 것은 아니다.

## 항목별 정량화 과정

|---|---|---|---|---|
| **Pull 힘 기준** | **15 N**을 정지 기준으로 사용 | 실물에서 기준 도달 후 감속 중 최대 힘이 약 **16.41 N**, 다른 기록에서는 **18~20 N대**까지 측정됨 | 정지 트리거와 최대 실측 힘을 구분해 기록 | **15 N 유지 제어가 아님.** 제품 규격에 적합한 기준인지는 추가 검증 필요 |
| **허용 변위** | Pull 변위 **5 mm 이하**를 합격 조건으로 설정 | 약 **6.31 mm**에서 변위 초과 FAIL 확인 | 힘에 도달해도 변위가 크면 FAIL로 판정 | 힘만으로 판단하지 않도록 한 기준. 정상·불량 샘플 분포에 따른 타당성 검증 필요 |

| **폭 완료 허용오차** | 목표와 실측 차이 **2.5 mm 이내** | 목표 **29 mm**, 실측 **32.5 mm**로 약 **3.5 mm** 차이가 나 타임아웃 | 허용오차 **5 mm**로 확대 | **오류 완화값**이며 측정 정확도 개선이나 기구 문제 해결을 뜻하지 않음 |
| **START/HOME 개방** | 공통 개방 **25 mm**, 초기 힘 **40 N** 동기화 | 기존 폭 재전송으로 닫힘이 발생할 수 있음을 코드에서 확인 | **30 mm 폭 우선 지정 → 힘 감소 동기화 → 10 N** | 개방 명령 순서를 개선. 첫 명령은 기존 드라이버 힘을 사용하며 실물 효과 확인 필요 |

| **작업영역** | 기존 범위로 검사 위치 분류 | 새 Entry가 X **-307.12 mm**, Z **780.28 mm**에 위치 | 전체·상부 X 하한 **-330 mm**, Z 상한 **800 mm** | 교시 위치에 여유를 둔 **운영 경계값**. 도달 가능성·충돌 안전을 보증하지 않음 |

## 근거가 명확한 개선과 추가 검증이 필요한 기준

가장 근거가 명확한 정량적 개선 사례는 Ready 좌표 오류 해결이다. 입력값 차이, 실측 오차, FK 재계산, 정정 후 오차까지 연결된다. 정정 관절각은 `[-231.39, -18.39, 132.47, -1.0, -113.56, -55.43]`, 직접 확인한 task는 `[-138.99, 155.74, 702.3, 9.05, -1.05, 64.53]`이다. 약 0.006 mm는 FK와 교시 표시값 사이의 XYZ 차이이며 로봇의 절대 정확도를 검증한 수치는 아니다.

힘·변위·파지 폭 기준은 실물에서 판정 동작을 확인한 단계다. 정상·불량 데이터를 충분히 모아 최적 임계값을 통계적으로 도출했다고 표현하지 않는다.

USB 후보로 찾은 14.7·15.1 mm 데이터의 실제 케이블 종류가 확인되면, 케이블별 정상 파지 폭과 판정 기준을 분리하는 것이 다음 과제다. 폭만으로 USB 또는 미끄러짐을 확정할 수 없다.

## 발표용 요약

> 힘·변위·파지 폭을 수치화해 검사 기준을 설정하고, 실측값과 명령값의 차이를 추적했습니다. 실패 원인에 따라 입력 오류는 정정하고, 동작 여유는 조정하며, 고정 수치로 해결되지 않는 복귀 문제는 경로 방식 자체를 변경했습니다.
