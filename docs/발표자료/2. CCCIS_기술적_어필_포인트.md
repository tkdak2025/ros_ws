# CCCIS 기술적 어필 포인트

| 순위 | 영역 | 핵심 어필 포인트 | 중요하게 다룰 이유·발표 메시지 |
| ------ | ---------- | ---------------------------- | ----------------------------------------------------------------------------- |
| **1** | **HMI·검사** | **운영 가능한 통합 검사 시스템** | 로봇 동작뿐 아니라 검사 시작·중단·재개·복귀·결과 조회까지 연결. **“단일 동작 시연을 넘어 실제 운영 흐름을 구현했다.”** |
| **2** | **HMI·검사** | **레시피 기반 검사 구성** | 좌표·순서·파지 조건·판정 기준을 데이터로 관리하고 다중 포인트 검사로 확장. **“코드 수정 없이 검사 구성을 전환한다.”** |
| **3** | **검사** | **힘·변위 기반 체결 판정** | 검사 목적과 가장 직접적으로 연결되는 기술. **“움직임의 성공이 아니라 측정값으로 체결 상태를 판단한다.”** |
| **4** | **검사** | **Adaptive Grip** | Soft Grip → 접촉 진입 → Hard Grip의 단계별 파지. **“작업 단계에 맞춰 파지 조건을 바꾸고 실측 폭을 확인한다.”** |
| **5** | **HMI** | **운영 중심 HMI와 결과 추적성** | 상태·실패 사유·과거 이력·검사 당시 조건·Excel 출력 제공. **“작업자와 품질 담당자가 활용할 수 있는 정보를 남긴다.”** |
| **6** | **검사** | **Safe Escape와 영역별 HOME 복귀** | 반복된 직선 이탈 실패를 실측 위치 기반 경유점 복귀로 개선. **“실물에서 발견한 제약을 복구 설계에 반영했다.”** |
| **7** | **HMI·검사** | **예외 상황과 후속 동작 차단** | STOP, 통신 감시, 개방·이동 실패 처리, 동시 모션 방지. **“정상 시나리오뿐 아니라 실패했을 때의 동작을 설계했다.”** |
| **8** | **HMI·검사** | **모듈화·비동기 판정 구조** | 장비 제어·시퀀스·판정·HMI 책임 분리. **“기능 변경과 장비 확장을 고려한 구조로 구현했다.”** |
| **9** | **검사** | **실측·FK 기반 문제 해결** | Ready 좌표 불일치를 추적해 J5 오기 발견. **“허용오차를 늘리는 데 그치지 않고 원인을 계산과 측정으로 확인했다.”** |
| **10** | **HMI·검사** | **자동시험과 실물 검증 병행** | 회귀시험·로그·Snapshot·체크리스트로 변경 검증. **“재현 가능한 근거로 구현 결과를 확인했다.”** |
