# Sequence #04 — Adaptive Grip

갱신: 2026-09-23. [05 반영 결과](../../작업내역/05_시퀀스_보류항목_반영결과_2026-09-23.md)와 현재 후속 파지 규칙을 적용한다. 기존 PDF는 갱신 전 보존본이다.

## 목적과 진입 조건

#03의 Ready → Entry pose 접근 이후 Soft Grip 상태로 케이블 방향 진입을 수행하고, Hard Grip 완료 후 Pull을 허용한다. 케이블 체결 판정은 이 단계에서 하지 않는다.

## 실행 순서

1. 레시피 Soft Grip 명령.
2. Entry task의 ZYZ 자세로 구한 Tool +Z 방향으로 추가 직선 진입. 케이블 축을 따라 접근해 Soft Grip 중 파지를 안정화하고 인접한 선으로의 횡방향 이동을 줄인다.
3. 거리/힘 Guard/timeout 중 먼저 도달한 조건에서 감속 정지.
4. Entry 종료 직후 새 폭 샘플을 읽어 `soft_width_mm` 기록. Busy 상태로 완료를 판정하지 않는다.
5. 레시피 Hard Grip 명령 후 목표 폭 허용범위 도달 또는 1.5초 폭 안정화로 완료 확인. Busy 상태는 사용하지 않는다.
6. `HARD_GRIP_DONE` 완료점 확인 후 #05 Pull.

추가 진입이 짧았다는 이유로 제품 FAIL로 판단하지 않는다. 별도 고정 settling delay는 없다. Soft 동작 종료 확인은 폭 측정의 유효성을 위한 것이다. Hard 목표 폭과 실제 폭의 일치로 케이블 파지 성공을 추정하지 않는다.

## 조건과 예외

Entry 거리 상한은 25 mm이며 timeout은 레시피의 유한한 양수 값이다. force_guard_n과 Soft/Hard 목표 폭·힘은 레시피의 유한한 양수다. 설정 상한 위반은 전송/초기화 검증에서 거절한다. 실제 그리퍼/모션 오류는 상위에 전달하고 Pull을 시작하지 않는다.

## 후속 합의

옛 Hard 직후 폭 기준은 Soft 종료 기준 폭으로 대체한다. 별도 entry_direction 전송 대신 Entry ABC로 방향을 정한다. 폭 차이는 기록용이고 Pull 중 최소 폭 16 mm 미만 판정은 #06에서 수행한다. 이 합의로 인해 구형 PDF의 Hard 폭/Slip 설명은 사용하지 않는다.

## 파지 실패 후속 정책

Hard 폭 완료 타임아웃은 해당 포인트 SYSTEM_ERROR로 기록하고 Pull을 생략한다. Open 폭 확인 → Entry 직선 후퇴 → Ready 복귀 성공 후 다음 포인트로 진행한다. Open/복귀 실패와 STOP·통신 오류는 중단한다. [09 상세 정책](../../작업내역/09_파지타임아웃_포인트복구_2026-09-23.md)을 따른다.

## 접촉 진입 거리 해석

여기서 진입은 Entry 교시 위치에서 Soft Grip 상태로 Tool +Z 방향에 추가 이동하는 구간이다. `max_distance_mm`는 이동 상한이며, 힘 한계에 먼저 도달하거나 로봇이 목표 전에 정지해도 실제 변위와 종료 사유를 기록하고 다음 파지 단계로 진행한다. 목표 거리 미도달만으로 Job 오류를 만들지 않는다. 로봇/서비스 오류, 실제 모션 정지 실패는 별도 오류다.
