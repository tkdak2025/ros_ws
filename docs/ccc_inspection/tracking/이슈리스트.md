# M0609 케이블 Pull 검사 이슈리스트

실물 M0609로 고정 검사 위치의 케이블을 파지하고 Pull을 수행하면서 힘과 TCP 위치를 기록하는 프로젝트의 이슈를 관리한다.

## 관리 규칙

- 필수 열은 `이슈번호`, `주요내용`, `세부내용`이며, 관리용 추가 열은 그 뒤에 배치한다.
- 새 이슈를 추가하는 작성자는 기존 번호의 최댓값에 1을 더해 `ISSUE-001` 형식으로 부여한다. 사용자가 번호를 지정할 필요는 없다.
- 기존 번호는 정렬·상태 변경 후에도 유지한다. 종료한 이슈도 삭제하지 않고 해결 내용을 남겨 번호 중복과 재사용을 방지한다.
- 세부내용에는 관찰 사실, 미확인 사항, 검사에 미치는 영향을 구분해 적는다. 추정 원인을 확정 사실로 기록하지 않는다.
- 변경 시 해당 행의 갱신일을 수정한다. 상태는 `해결`, `진행 중`, `대기(보류)` 세 가지로 관리한다.
- 이 Markdown 문서는 표 형태의 관리 대장이다. 번호 부여는 문서에 이슈를 추가할 때 수행하며, 문서 자체에 실행되는 자동화 기능은 없다.


- `해결`: 해당 이슈 범위의 수정·작성·검증을 완료했다. 문서·설정 작업의 해결이 실물 시험 완료를 뜻하지는 않는다.
- `진행 중`: 구현·원인 확인·검증 중이거나 완료 검증이 남아 있다.
- `대기(보류)`: 미착수·후속 범위 또는 선행 조건을 기다리는 작업이다. 재개 조건을 확인 계획에 적는다.
- 상세 관찰 기록은 당시의 사실·가설을 보존한다. 현재 상태와 조건은 아래 현황 표를 우선한다.
