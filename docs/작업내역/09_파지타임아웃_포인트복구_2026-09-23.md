# 09. 파지 타임아웃 포인트 복구

초기 합의는 Soft/Hard 파지 완료 타임아웃 시 해당 포인트 실패를 기록하고 다음 포인트로 진행하는 것이었다. 2026-09-25 변경에 따라 Busy 기반 완료 대기를 제거했다.

## 적용 흐름

Soft 기준 폭은 Entry 종료 직후 새 샘플로 읽으며 Busy를 기다리지 않는다. Hard는 목표 폭 허용범위 도달 또는 1.5초 동안 실측 폭 변화가 0.2 mm 이내면 완료한다. 둘 다 미도달해 Hard 완료 시간이 초과된 경우에만 GripCompletionTimeout으로 구분하고 Pull을 생략한다.

1. TIMEOUT 판정 요청과 HARD_GRIP_TIMEOUT 사유를 기록한다.
2. 해당 포인트 레시피의 Open 폭으로 열고 실측 폭 허용오차를 확인한다.
3. 기존 Entry task로 직선 후퇴하고 Ready로 MoveJ 복귀한다.
4. 복귀 완료 후 다음 포인트를 진행한다. 마지막 포인트라면 기존 Work Finish 및 Home으로 진행한다.

파지 실패는 제품 불량으로 추론하지 않는다. 기존 인터페이스의 SYSTEM_ERROR, judgment_status=ERROR, sequence_status=INCOMPLETE로 판정하며 별도 메시지 필드는 추가하지 않는다. 로컬 결과에는 adaptive_grip_done=false, Pull skipped 및 복구 결과를 남긴다. Runtime의 adaptive_grip_status=FAIL, pull_status=INCOMPLETE이고, 복귀 성공 후 motion_status=SUCCESS이므로 PR #9 완료 정책과 호환된다. 미실시 Pull의 0 값은 성공 측정값이 아니라 TIMEOUT/미실시 기록이다.

## 중단 유지 조건

사용자 STOP, 통신/서비스 오류, 새 그리퍼 피드백 수신 실패, 로봇 이동 오류는 일반 예외 경로를 유지한다. 복구 Open 실패·폭 미도달 또는 Entry/Ready 복귀 실패도 다음 포인트로 넘어가지 않는다. 파지 타임아웃을 복구하는 try 범위에 복구 동작 자체를 포함하지 않는다.

## 검증

2026-09-25 검사 패키지 전체 테스트: 164 passed, 1 skipped. Hard timeout 뒤 다음 포인트 진행·Pull 생략·SYSTEM_ERROR 기록과 Open/Entry/Ready/STOP/통신 실패 시 후속 포인트 차단을 확인했다. 정상·반체결 원본 폭 샘플을 새 Hard 완료 조건에 재생했고 실물 로봇 운전은 수행하지 않았다.
