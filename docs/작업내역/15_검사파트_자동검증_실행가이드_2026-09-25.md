# 검사파트 자동검증 실행 가이드

검증 코드: [`../../src/cable_inspection/cable_inspection/diagnostics/check_inspection.py`](../../src/cable_inspection/cable_inspection/diagnostics/check_inspection.py)

## 실행

프로젝트의 `ros_ws` 폴더에서 실행한다. ROS Jazzy와 빌드된 검사 패키지, pytest가 필요하다.

```bash
source /opt/ros/jazzy/setup.bash
source install/setup.bash
python3 src/cable_inspection/cable_inspection/diagnostics/check_inspection.py --with-ros
```

- 기본 실행은 모의 측정값을 운영 시퀀스에 입력하는 정량 비교와 기존 오프라인 회귀 테스트를 수행한다.
- `--with-ros`는 모의 ROS 통합시험을 추가한다. 도메인 232와 LOCALHOST를 사용하며 로컬 Doosan 드라이버 설치 환경이 필요하다.
- `--output /tmp/inspection-check-001`로 새 결과 폴더를 지정할 수 있다. 기존 폴더는 덮어쓰지 않는다.
- 실행기는 `src/cable_inspection/test/`의 시험 코드와 입력 대역을 재사용하므로 이 파일만 다른 위치로 복사해서 실행할 수는 없다.

## 결과

기본 저장 위치는 `results/checklist/<실행시각>/`이다.

| 파일 | 내용 |
|---|---|
| `report.md` | 기대값·측정값·오차·통과 여부, 체크리스트별 자동검증 범위, 개별 시험 결과 |
| `offline.log`, `offline.xml` | 오프라인 시험 실행 로그와 JUnit 결과 |
| `ros.log`, `ros.xml` | 선택 실행한 ROS 통합시험 로그와 JUnit 결과 |
| `evidence/*.json` | 재현 입력과 명령·측정값 증거 |

정량 비교는 힘 제한, 거리 제한, 이동 미달, 타임아웃, 파지 상태별 결과와 START 위치별 준비 경로를 확인한다. 수치 오차 허용값은 보고서에 기록하며, 모의 데이터 비교 정밀도이지 실물 센서 정확도가 아니다. 예상 판정이 FAIL인 케이스도 실제 판정이 기대값과 일치하면 검증 결과는 PASS이다.

종료 코드 0은 실행한 자동검증 통과, 1은 실패·건너뛴 시험·실행 오류를 뜻한다. 환경 준비 오류나 기존 출력 폴더 지정도 비정상 종료한다.

## 검증 범위

체크리스트는 자동시험과 연결되더라도 **자동 부분 통과**로 표시한다. 각 항목의 모든 현장 동작을 확인했다는 뜻은 아니다. 입력은 시험용 고정 데이터이며 현재 운영 레시피 전체를 실물이나 가상 컨트롤러에서 운전하는 프로그램은 아니다.

실물 장비에는 명령을 보내지 않는다. Tool 방향, 그리퍼 Open 25 mm, 후퇴 30 mm의 적합성, 실제 케이블 간섭과 판정 임계값은 체크리스트 R01~R05에 따라 별도로 확인해야 한다. 수동 HOME의 Work Access 처리 정책도 보고서의 별도 확인 사항에 남긴다.
