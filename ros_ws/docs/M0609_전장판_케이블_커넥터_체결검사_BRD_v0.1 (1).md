# M0609 기반 다품종 전장판 케이블·커넥터 체결상태 검사 시스템 BRD

**대상 시스템:** Doosan Robotics M0609 + OnRobot RG2 기반 접촉식

**개발 단계:** Phase 1 중심 / Phase 2 확장 정의

## 1. 프로젝트 개요

### 1.1 프로젝트명

**M0609 기반 다품종 전장판 케이블·커넥터 접촉식 체결상태 검사 시스템**

### 1.2 배경

전장판에는 제품별로 다수의 케이블, 커넥터 및 고정부가 존재하며 검사
위치와 접근 방향이 서로 다를 수 있다.\
본 프로젝트는 고정된 단일 검사장비보다 6축 매니퓰레이터의 위치·자세 변경
능력을 활용하여, 제품별 검사 포인트를 Recipe로 정의하고 여러 방향에서
접촉식 체결검사를 수행하는 소형 PoC를 구현한다.

Phase 1에서는 **이미 조립된 상태의 전장판을 검사**한다. 로봇이 커넥터를
조립하거나 재체결하는 기능은 범위에 포함하지 않는다.

### 1.3 핵심 목표

1.  제품별 필수 검사 포인트를 Recipe로 관리한다.
2.  M0609이 수직하강면, 측면, 상부면의 검사 포인트에 서로 다른 TCP
    자세로 접근한다.
3.  RG2로 케이블 또는 커넥터 하우징을 안정적으로 파지한다.
4.  Pull Test를 우선 구현하여 체결·고정 이상 여부를 정량적으로 판정한다.
5.  검사 포인트별 PASS/FAIL과 측정값을 검사 결과 Sheet로 제공한다.
6.  향후 Vision 및 조립검사 기능을 확장할 수 있는 구조로 설계한다.

## 2. 타깃 도메인 및 PoC 정의

### 2.1 타깃 도메인

-   자동차 및 산업용 전장판
-   Wiring Harness
-   전장 커넥터 및 케이블 고정부
-   다품종·다변량 생산환경
-   제품별 검사 포인트와 접근 방향이 달라지는 검사공정

### 2.2 PoC 검사 대상

실제 자동차용 커넥터 사용을 필수 조건으로 하지 않는다.\
PoC에서는 다음 물리적 특성을 재현할 수 있는 플라스틱 Connector/Cable
Mock-up을 사용할 수 있다.

-   RG2가 안정적으로 파지 가능한 형상
-   정상 체결 상태에서 지정된 Pull Force에 버틸 수 있음
-   반체결 또는 고정불량 상태에서 정상과 구분 가능한 변위 또는 이탈이
    발생함
-   반복적인 체결/분리 및 불량 재현이 가능함
-   수직하강, 측면, 상부 방향 Fixture에 설치 가능함

**중요:** Mock-up 결과는 실제 자동차 커넥터의 성능 검증이 아니라, 다방향
접촉식 체결검사 공정의 원리와 제어 가능성을 검증하는 PoC로 정의한다.

## 4. 검사 방법

### 4.1 Phase 1 우선 검사 - Pull Test

**Pull Test(당김 검사)**는 RG2가 체결된 케이블 또는 커넥터를 파지한 후,
체결이 풀리는 방향으로 제한된 힘을 가하여 체결 상태를 확인하는 접촉식
검사이다.

기본 판정 개념:

-   동일한 시험 힘에서 변위가 작고 체결이 유지됨 → 정상 후보
-   동일한 시험 힘에서 변위가 기준을 초과함 → 체결 이상 후보
-   검사 중 대상이 이탈함 → 불량

개념식:

`F_test = 지정 시험 힘`

`Δx < x_limit -> PASS`

`Δx >= x_limit 또는 이탈 -> FAIL`

실제 Force/Displacement 기준값은 시편 선정 후 반복실험을 통해 결정한다.

### 4.2 커넥터 검사

RG2가 가능하면 케이블이 아닌 **Connector Housing**을 직접 파지한다.

검사항목 예: - 완전 체결 여부 - 반체결 여부 - Lock 유지 여부 - Pull
Force 인가 시 비정상 변위 - 이탈 여부

### 4.3 케이블 고정 검사

케이블 자체 또는 케이블 고정부 주변을 RG2로 파지하여 Pull Test를
수행한다.

검사항목 예: - Harness Clip 고정 상태 - 케이블 고정부 이탈 여부 - 지정
Force에서의 과도한 이동 - 고정 위치별 PASS/FAIL

### 4.4 향후 추가 가능한 검사

-   **Lateral Test:** 케이블/커넥터를 체결축과 직각인 옆 방향으로 작은
    힘을 가해 유격이나 고정 이상을 확인하는 검사.
-   **Wiggle Test:** 케이블/커넥터를 작은 범위에서 좌우 또는 각도
    방향으로 흔들어 체결부의 유격과 Force/Torque 반응을 확인하는 검사.

Lateral/Wiggle Test는 Phase 1 필수범위가 아니며 Pull Test 안정화 이후
확장 기능으로 검토한다.

## 6. RG2 파지 요구사항

### 6.1 Connector 파지

우선적으로 Connector Housing의 평행한 외벽을 양쪽 Finger로 파지한다.

요구사항: - 파지 시 Connector Lock 구조를 직접 누르지 않을 것 - Pull
방향과 파지 방향이 충돌하지 않을 것 - 검사력보다 충분한 파지 마찰력을
확보할 것 - 과도한 Grip Force로 플라스틱 시편을 변형시키지 않을 것 -
측면 및 상부 검사에서도 Finger와 Fixture 간 간섭이 없을 것

### 6.2 Cable 파지

케이블은 변형 가능한 대상이므로 Connector보다 파지가 어렵다.

우선 검토 방향: - 케이블 단일 선재보다 Harness 형태의 비교적 굵은 케이블
사용 - 케이블 피복 손상을 방지하는 낮은 Grip Force 사용 - 필요 시 RG2
Finger에 탈착식 고무 패드 또는 단순 보조 Jaw 적용 - Cable Pull 시
미끄러짐과 실제 체결부 이동을 구분할 수 있도록 Robot displacement만으로
판정하지 않음

### 6.3 주요 위험

-   RG2 Finger에서 케이블이 미끄러질 수 있음
-   파지 과정에서 커넥터 Lock을 눌러 체결을 해제할 수 있음
-   좁은 검사 위치에서 RG2 Body/Finger가 전장판과 충돌할 수 있음
-   파지력 자체가 검사 결과에 영향을 줄 수 있음

따라서 초기 시편 선정 시 **파지 용이성**을 핵심 조건으로 둔다.

## 7. 검사 결과 Sheet 요구사항

검사 완료 후 제품 단위의 결과를 표 형태로 제공한다.

### 7.1 결과 Sheet 예시

  Point   대상        접근 방향     Test Force   Displacement 결과
  ------- ----------- ----------- ------------ -------------- ------
  P01     Connector   수직하강             5 N         0.4 mm PASS
  P02     Cable       측면                 4 N         2.1 mm FAIL
  P03     Connector   상부                 5 N         0.6 mm PASS

### 7.2 필수 기록 데이터

-   검사 일시
-   Product/Recipe ID
-   Inspection Point ID
-   Target Type
-   접근 방향
-   RG2 Grip 설정
-   Test Force
-   최대 Force
-   시작/종료 Robot Position
-   계산된 Displacement
-   PASS/FAIL
-   Error/Abort 여부

### 7.3 최종 판정

-   모든 필수 검사 Point PASS → Product PASS
-   필수 Point 중 하나 이상 FAIL → Product FAIL
-   검사 미수행/통신/Force Limit 등의 오류 → 별도 ERROR 상태

## 10. Phase 구분

### Phase 1 - 접촉식 체결상태 검사

**필수** - 2\~3개 Recipe - 수직하강/측면/상부 3방향 접근 - Connector
Housing 파지 - Cable 파지 - Pull Test - Force/Displacement 측정 -
PASS/FAIL 판정 - 결과 Sheet 생성

**선택 확장** - Lateral Test - Wiggle Test - Force Signature 비교

### Phase 2 - Vision 기반 검사 자동화

향후 Camera/Vision을 추가하여 다음을 검토한다.

-   제품 종류 인식
-   Recipe 자동 선택
-   Connector/Cable 검사 Point 검출
-   제품 Pose 변화에 따른 검사 좌표 보정
-   검사 대상 접근 자동화

Vision의 역할은 **검사 대상의 위치·자세를 인식하고 Robot 접근 좌표를
보정하는 것**이며, 실제 체결상태 판단은 접촉식 Force/Displacement 검사를
유지한다.

### Phase 3 - 조립 및 Recovery 확장

Phase 1/2가 안정화된 이후 선택적으로 검토한다.

-   Connector 자동 조립
-   체결 이상 감지 후 Retract
-   Search/Alignment Motion
-   재체결
-   조립 후 자동 재검사

Phase 3는 현재 미니프로젝트 범위에 포함하지 않는다.

## 11. M0609 사용 타당성

본 프로젝트에서 M0609의 핵심 가치는 단순 Pull Force 발생이 아니라
**제품별로 서로 다른 위치와 방향에 존재하는 검사 Point에 접근하는 6축
Manipulation 능력**이다.

특히 시연에서는: - 수직하강 검사 - 측면 검사 - 상부/천장면 검사

를 연속 수행하여 Position뿐 아니라 TCP Orientation 변경이 실제 검사
요구사항임을 보여준다.

또한 Force/Compliance 기능을 Pull Test 및 안전한 접촉검사에 활용할 수
있으며, 향후 Vision과 결합하면 고정된 전용 검사 Fixture보다 제품 변화에
대응하는 Flexible Inspection 구조로 확장할 수 있다.

### 핵심 기술 위험

1.  Cable 파지 중 미끄러짐이 실제 체결부 변위로 오인될 수 있음.
2.  Connector Housing 파지 시 Lock Release 구조를 건드릴 수 있음.
3.  정상/반체결 상태의 Force/Displacement 차이가 충분하지 않을 수 있음.
4.  상부/측면 접근 시 RG2와 Fixture의 기구 간섭 가능성이 있음.
5.  Mock-up에서 얻은 Threshold를 실제 자동차 전장품에 그대로 적용할 수
    없음.

## 13. PoC 성공 기준

Phase 1은 다음을 만족하면 성공으로 판단한다.

1.  최소 2개 이상의 제품 Recipe가 동작한다.
2.  수직하강, 측면, 상부의 3개 접근 방향을 M0609으로 시연한다.
3.  RG2로 Connector와 Cable을 각각 파지하여 Pull Test를 수행한다.
4.  정상 시편과 의도적으로 만든 체결불량 시편 사이에 반복 가능한 측정
    차이가 확인된다.
5.  정의된 판정기준으로 Point별 PASS/FAIL을 생성한다.
6.  전체 검사 결과가 Product/Recipe 단위 Sheet로 출력된다.
7.  Force Limit 초과 또는 검사 실패 시 안전하게 중단할 수 있다.
